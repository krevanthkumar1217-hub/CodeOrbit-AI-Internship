# CodeOrbit Rule-Based Chatbot

This is a simple rule-based chatbot built using Python as part of my CodeOrbit Tech Artificial Intelligence Internship.

## Features
* Responds to basic greetings (like hi, hello, hey).
* Handles specific keywords related to the internship and well-being.
* Includes a built-in fallback response to gracefully handle unknown user inputs.
* Uses clean, beginner-friendly Python logic (`if-else` statements).

## How to Run
1. Open your terminal or command prompt.
2. Navigate to the folder containing the script.
3. Run the following command:
   ```bash
   python chatbot.py
