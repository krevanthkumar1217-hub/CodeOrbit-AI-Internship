# CodeOrbit Tic-Tac-Toe with Simple AI

A simple command-line Tic-Tac-Toe game where a user plays against a rule-based AI opponent. Built in Python for the CodeOrbit Tech AI Internship.

## Features
- Interactive 3x3 grid displayed after every move.
- Rule-based AI that looks ahead to win or block player moves.
- Automatically checks for win, loss, and draw conditions.

## How to Run
1. Open your terminal or command prompt.
2. Navigate to this folder.
3. Run the script:
   ```bash
   python tic_tac_toe.py
